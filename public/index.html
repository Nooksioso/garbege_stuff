    Настройка приложения

    страница настроек: выводится файл заглушки public/placeholder.html
    Архитектура. Браузер (HTML + JS, fetch) общается с сервером по REST API; данные — на сервере: журнал и сессии в data/database.json, справочник сотрудников — в data/employees.json, проекты — в data/projects.json, готовые аватарки — в public/avatars. Один сервер — сколько угодно клиентов: откройте http://<IP-сервера>:8080 с любой машины в сети. Записи хранят «фотографию» имени сотрудника, поэтому история не теряется даже при удалении человека из справочника.
    • GET /api/employees — справочник сотрудников
    • GET /api/avatars — готовые аватарки (public/avatars)
    • POST /api/employees — внести сотрудника
    • PUT /api/employees/:id — отредактировать
    • DEL /api/employees/:id — удалить
    • GET /api/projects — проекты (список — всем; управление — администратор)
    • POST /api/projects — новый проект
    • PUT /api/projects/:id — отредактировать проект
    • DEL /api/projects/:id — удалить проект
    • GET /api/entries — записи журнала
    • POST /api/entries — новая запись (архивная дата — только администратор)
    • PUT /api/entries/:id — корректировка (архивные записи — только администратор)
    • DEL /api/entries/:id — удалить запись (архивные — только администратор)
    • POST /api/print — печать: неделя → temporary/raport.csv
    • GET /api/stats — сводка · /api/health — статус
    • GET /api/setup — настройки приложения (data/setup.json, версия)
