    Архитектура. Браузер (HTML + JS, fetch) общается с сервером по REST API; данные — на сервере: журнал и сессии в data/stufftime.json, справочник сотрудников — в data/employees.json, проекты — в data/projects.json, готовые аватарки — в public/avatars. Один сервер — сколько угодно клиентов: откройте http://<IP-сервера>:8080 с любой машины в сети. Записи хранят «фотографию» имени сотрудника, поэтому история не теряется даже при удалении человека из справочника.
    • GET /api/employees — справочник сотрудников
    • GET /api/avatars — готовые аватарки (public/avatars)
    • POST /api/employees — внести сотрудника
    • PUT /api/employees/:id — отредактировать
    • DEL /api/employees/:id — удалить
    • GET /api/projects — проекты (список — всем; управление — администратор)
    • POST /api/projects — новый проект
    • PUT /api/projects/:id — отредактировать проект
    • DEL /api/projects/:id — удалить проект
    • GET /api/entries — записи журнала
    • POST /api/entries — новая запись
    • PUT /api/entries/:id — корректировка
    • DEL /api/entries/:id — удалить запись
    • GET /api/stats — сводка · /api/health — статус
