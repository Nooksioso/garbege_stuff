# Garbege stUff — What's New

История изменений приложения **Garbege stUff** (учёт рабочего времени сотрудников).
Версия приложения — переменная `version` в файле настроек `data/setup.json`.

## Версия 1.1

- Таблица «Задачи»: в столбце «Сотрудник» выводится только имя сотрудника — подпись должности под именем убрана (должность по-прежнему видна в справочнике «Сотрудники» и на экране входа).
- Шапка приложения: убрана аватарка текущего пользователя — в строке «вход: …» остались имя и кнопка «Выйти» (аватар по-прежнему виден в боковой панели — в подписи текущего пользователя, а также на экране входа и в справочнике).
- Значение переменной `version` в `data/setup.json` повышено: `1.0` → `1.1` (значения по умолчанию в `server.js` обновлены; «Garbege stUff ver 1.1»).
- Обновлена документация (README): ссылки на версию приведены к 1.1.

## Версия 1.0

- **Сворачиваемое боковое меню (администратор)**: кнопка ««/»» в шапке панели — меню сворачивается «вбок» в узкую колонку иконок: скрываются тексты пунктов, заголовок группы «Справочники», имя и роль текущего пользователя, панель сужается (переход ширины плавный); повторное нажатие — разворачивает меню. Состояние (свёрнуто/развёрнуто) запоминается в браузере (localStorage, ключ `stufftime_sidebar`) и восстанавливается при следующем входе — до первой отрисовки, чтобы панель не «прыгала»; на узких экранах (горизонтальное меню) сворачивание не применяется.
- **Группа «Справочники» в боковом меню**: справочники **Сотрудники** и **Проекты** собраны под заголовком «Справочники»; рядом — **заготовки для новых справочников «Должности» и «Заказчики»**: пункты уже стоят в меню (у иконки — пунктирная рамка, подсказка «функционал в разработке»), по клику открывается страница-заготовка с баннером «🚧 Функционал в разработке» (выводится файл заглушки `public/placeholder.html`, как на странице «Настройка приложения»).
- Значение переменной `version` в `data/setup.json` повышено: `0.9` → `1.0` (значения по умолчанию в `server.js` обновлены; «Garbege stUff ver 1.0»).
- Обновлена документация (README): раздел «Возможности» (пункт «Боковая панель (администратор)»), структура проекта, «Данные и сброс»; ссылки на версию приведены к 1.0.

## Версия 0.9

- Исправлено: верхние карточки сводки не обновлялись при переключении недель — раньше пересчёт происходил только при обновлении данных журнала. Теперь при нажатии «← Назад» / «Вперёд →» карточки сразу пересчитываются за выбранную неделю (вместе с таблицей «Задачи»).
- Карточки сводки стали компактнее: уменьшены минимальная ширина карточки, отступы и размер цифры часов (все 8 карточек — 7 дней недели + итог за неделю — теперь помещаются в одну линию даже для администратора, с учётом боковой панели).
- Синхронизация цвета: карточка каждого дня недели получила тот же цвет, что и строки таблицы задач за ту же дату — общая палитра d0–d5: фон карточки совпадает с фоном строки, а цветная полоса карточки — с левым краем строки (цвет зависит от даты, как и у строк).
- Значение переменной `version` в `data/setup.json` повышено: `0.8` → `0.9` (значения по умолчанию в `server.js` обновлены; «Garbege stUff ver 0.9»).
- Обновлена документация (README): раздел «Возможности» (пункт «Сводка (карточки сверху)»), структура проекта, «Данные и сброс»; ссылки на версию приведены к 0.9.

## Версия 0.8

- Кнопка 🖨️ «Печать» (вкладка «Задачи»): при нажатии браузер предлагает скачать файл `raport.csv` на компьютер пользователя (UTF-8 с BOM, разделитель «;»); содержимое CSV возвращается в ответе API (`POST /api/print` — новое поле `csv`). Файл по-прежнему сохраняется и на сервере в `temporary/raport.csv`.
- Переработана верхняя панель со сводкой: вместо прежних карточек (записей в журнале, часов сегодня, часов в месяце, сотрудников в справочнике) — карточки за **выбранную неделю** для **текущего пользователя**: сколько часов было потрачено на задачи в каждый день недели (Пн — Вс, с датами) и сколько **суммарно часов за неделю** (акцентная карточка). Дни без записей показаны приглушённо; при переключении недель карточки пересчитываются.
- Значение переменной `version` в `data/setup.json` повышено: `0.7` → `0.8` (значения по умолчанию в `server.js` обновлены; «Garbege stUff ver 0.8»).
- Обновлена документация (README): раздел «Возможности» (пункты «Печать», новый пункт «Сводка (карточки сверху)»), таблица API (`POST /api/print`), «Данные и сброс»; ссылки на версию приведены к 0.8.

## Версия 0.7

- Новая строка в журнале: поле «Сотрудник» теперь по умолчанию заполняется данными текущей учётной записи (под которой выполнен вход в систему) — и для администратора, и для исполнителя; администратор при необходимости может выбрать другого сотрудника из списка.
- Выбор задачи: если из списка уже выбран вариант, при повторном вызове списка (поле «Задача») фильтр очищается и отображаются все проекты из справочника «Проекты»; как только пользователь начинает вводить текст — снова работает поиск по наименованию или номеру.
- Таблица «Задачи»: при выводе задач нескольких сотрудников строки группируются по Сотрудникам — строка-заголовок на каждого сотрудника (группы по алфавиту, с количеством записей), внутри группы — по дате (сначала новые); при выводе одного сотрудника таблица остаётся в обычном порядке (по дате).
- Значение переменной `version` в `data/setup.json` повышено: `0.6` → `0.7` (значения по умолчанию в `server.js` обновлены; «Garbege stUff ver 0.7»).
- Обновлена документация (README): раздел «Возможности» (пункты «Добавление строк», «Задача — только из справочника «Проекты»», новый пункт «Группировка строк по сотрудникам»), ссылки на версию приведены к 0.7.

## Версия 0.6

- Исправлено сохранение строки в таблице «Задачи»: раньше после попытки сохранить строку с ошибкой в любом поле (пустая задача, неверные часы и т.п.) кнопка ✓ в строке оставалась заблокированной — сохранить исправленную строку (кнопкой ✓ или клавишей Enter) было невозможно, а новую строку создать — только после удаления текущей. Теперь при ошибке проверки кнопка снова становится активной: как только все поля исправлены, строку можно сохранить — работают и кнопка ✓, и Enter.
- Значение переменной `version` в `data/setup.json` повышено: `0.5` → `0.6` (значения по умолчанию в `server.js` обновлены; «Garbege stUff ver 0.6»).
- Обновлена документация (README): ссылки на версию приведены к 0.6.
